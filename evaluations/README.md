# 실제 작업 기록

평가자는 실제 수작업과 앱 사용을 수행한다. 이 폴더는 결과를 기록·집계할 뿐 API를 호출하지 않는다.
진행 순서와 품질 기준은 [평가 계획](../docs/evaluation-protocol.md)을 따른다.

## 시작

```bash
cp evaluations/records.example.csv evaluations/records.csv
# records.csv에 실제 수행한 결과를 작성한다.
.venv/bin/python -m evaluations > evaluations/comparison.csv
```

다른 실험 회차는 `.venv/bin/python -m evaluations evaluations/records-v2.csv`처럼 별도 파일로 집계한다.
기록표는 비어 있다. 실험 전에 결과나 사람 점수를 채우지 않는다.

## 한 행에 적는 내용

- `case_id`: 같은 자료·완료 조건을 사용하는 비교 과제 ID.
- `scenario`: first_use(첫 사용, 스타일 설정 포함) 또는 repeat_use(반복 사용, 저장된 스타일 재사용). 두 시나리오는 따로 비교한다.
- `method`: manual(원본 사진을 수정 없이 사용하고 문구를 직접 작성) 또는 service(실제 앱에서 스타일·문구·이미지 생성과 확정).
- `evaluator`: 실제 수행한 사람의 식별자. 같은 사람끼리 비교한다. 본인/동료/강사 관계는 notes에 적는다.
- `version`: 수작업 도구 이름·버전 또는 실제 앱 Git 커밋. 앱 커밋은 `git rev-parse --short HEAD`로 확인한다.
- `seconds`: 실제 측정한 전체 작업 초. first_use는 로그인 완료 후 스타일 설정 시작부터, repeat_use는 저장된 스타일로 새 콘텐츠 제작 시작부터 확정 성공까지 잰다. 수작업은 참고자료·문구 말투/서식 준비(첫 사용) 또는 기존 서식으로 새 제작 시작(반복 사용)부터 원본 사진·최종 문구가 게시 준비되어 저장되고 완성을 선언한 시점까지다. 게시 시간은 제외한다.
- `satisfaction`: 평가 계획의 1~5 만족도.
- `facts_ok`, `product_ok`, `usable`: yes / no / unreviewed. 상품 보존이 적용되지 않을 때만 product_ok에 na.
- `style_ok`: 피드 일관성의 사람 판정(yes / no / unreviewed). 양쪽의 여러 결과 사진을 같은 순서·배치로 나란히 보고 가게 참고자료와의 적합성, 색감·조명·배경 분위기의 일관성을 평가한다. 한 장만으로 판정하지 않는다.
- `notes`: 입력·원본/최종 결과와 나란히 본 사진 묶음의 보관 위치, 시작 상태·판정 근거·수행 순서·평가자 관계·실패 사유. 문구 말투의 적합성도 적는다. 수작업 사진은 수정 없이 평가하며 서비스가 더 일관적이라고 미리 판정하지 않는다.

수정 횟수는 기록·집계하지 않는다. 이미지 생성 한도와 비용 제한 코드는 유지한다.

완료하지 못한 작업은 중단 시점까지 걸린 시간과 usable=no, 사유를 남긴다.
아직 수행하지 않은 작업을 0초로 입력하지 않는다. 미평가 시간을 API 시간으로 채우지 않는다.

## 집계 결과

- `comparable`: 양쪽 결과의 사실·상품 보존·사용 가능 판정을 통과한 시간 비교. 피드 일관성은 별도로 표시한다.
- `quality_not_met`: 품질 조건 미충족. 전체 결과에는 남기고 시간 절감률은 계산하지 않는다.
- `awaiting_review`: 사람 판정 대기.
- `missing_pair`: 같은 과제·사용 시나리오·평가자의 다른 방식 기록이 없음.

시간 절감률 = (수작업 초 - 서비스 초) / 수작업 초 × 100. 음수이면 서비스가 더 오래 걸렸다는 뜻이다.
기록 전체는 원본 CSV에 보존하고 결과 CSV에는 사용 시나리오·버전·시간·만족도·피드 일관성·비교 상태를 출력한다. 일관성의 no/unreviewed 때문에 시간 비교를 숨기지 않는다. unreviewed를 일관성 개선 증거로 쓰지 않는다.
서비스가 더 오래 걸리면 시간 절감이라고 주장하지 않는다. 일관성도 개선된 경우에만 일관성 유지에 든 추가 시간으로 보고한다. 시간과 일관성을 하나의 점수로 합치지 않는다.
같은 사진 묶음의 일관성 판정을 여러 행에 적더라도 독립된 평가 건수로 중복 합산하지 않는다.
first_use와 repeat_use의 결과를 섞어 하나의 시간 절감률로 요약하지 않는다.
CSV 집계는 수행 조건이 실제로 같았는지 대신 확인해 주지 않으므로 과제 자료와 notes를 함께 검토한다.

반응 분석은 제작 비교 이후 분석 정확성·타당성·추천 반영 정확성으로 별도 평가하며 이 CSV에 합산하지 않는다.

개인 기록은 Git에서 제외한다. 공개 보고서는 평가자·사진·비밀값을 확인한 뒤 필요한 수치만 별도로 공유한다.
