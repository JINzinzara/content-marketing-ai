실제 GPT 호출은 `710c2abdd6b61aa0d7cac10b0bd0c9fc0b62eb98d218e93c25c8ac75d96c7921` 소스 스냅샷에서 수행한 과거 파일럿이다. 자동 검사는 이후 CLI 통합본에서 재실행했으며 두 실험의 소스 해시를 구분한다. 원본 입력·응답·사진·DB·소스 ZIP과 `.env`는 공개 결과에 포함하지 않는다. 이번 GitHub 반영 과정에서 유료 API를 재호출하지 않았다.

API 응답 수신은 최종 품질 통과와 다르다. 합성 단색 이미지를 사용했으며 실제 상품 이미지·사용자 전체 작업 시간·마케팅 성과·실제 Instagram 연결 성공을 검증하지 않았다. 사람 평가와 시간 절감률은 미측정이다. 비용은 설정된 단가로 계산한 앱 기록액이며 공급자 청구서와 다를 수 있다.
