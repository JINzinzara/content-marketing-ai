# 스푸키쿠키 모델 비교 — 확정 기준

기준일: 2026-10-28. 사용자 최신 지시와 후속 답변을 적용한다.
현재 단계는 평가 기준·자료 준비와 폐기된 비교 기능 정리다. 새 모델 비교 실행기와 유료 비교 결과가 완성됐다는 뜻은 아니다.

## 비교 대상과 실행 단위

- 문구: `gpt-5.4-mini` vs `gpt-5.4`.
- 이미지 편집: `gpt-image-1-mini` vs `gpt-image-2`.
- 원본 1장 + 각도 변형 2장 + 조명 변형 2장, 총 5개 입력을 사용한다.
- **사진마다 모델별로 한 번씩 생성한다. 모델당 5개 결과이며 사진당 5회 반복하거나 모델당 25개 결과를 생성하지 않는다.**
- 최초 시도 기준으로 문구 10건, 이미지 10건을 계획한다. 이는 생성 시도의 수이며 토큰 사전 계산 등 모든 HTTP 요청의 수가 아니다.
- 동일 입력을 반복하지 않으므로 생성 자체의 무작위 변동에 대한 반복 안정성을 따로 입증한 것으로 표현하지 않는다.
- 탐색은 자유다. 최종 비교 전에 모델별 품질·크기·출력 한도·추론 설정·프롬프트와 재생성 규칙을 고정해 기록한다. 다른 후보를 임의로 대체하지 않는다.
- 최종 비교는 각 입력의 최초 시도를 남긴다. 추가 품질 재생성은 탐색으로 분리하고 최종 비교의 5개 결과와 섞지 않는다.
- 문구 비교와 이미지 비교를 분리한다. 문구 비교 때 이미지 조건을, 이미지 비교 때 문구 조건을 고정한다.
- 최종 후보·설정을 고정한 뒤 생성 중 실패·거절·결과 불명도 그대로 기록한다. 좋은 결과만 골라 대체하지 않는다.
- 현재 앱의 비용·소유권·중복 요청·결과 불명 보호는 유지한다.

5개 입력과 모델당 5개 결과는 사용자가 정한 사례 범위다. 통계적으로 검증된 최적 표본 수나 실제 카페 사진의 대표 표본 수를 뜻하지 않는다.

## 입력 사실과 가게 스타일

- 상품명: 스푸키쿠키. 종류: 쿠키.
- 판매 조건: **10월 26일~11월 6일 할로윈 한정 판매**.
- 원본 파일: `cafenew3.jpg`.
- 확인하지 않은 가격·재료·식감·제조 방식을 사실처럼 추가하지 않는다.
- 하얀 장식의 실제 재료를 사진만으로 마시멜로 등으로 확정하지 않는다.
- 가게 이름: codeit.
- 소개: 대구광역시 OO동 카페. 아인슈페너 맛집. 구움과자 맛집. OO동은 임시 표기이며 실제 동네·주소로 확정하지 않는다.
- 분위기: 우드 톤과 크림/화이트를 중심으로 한 따뜻하고 정돈된 카페 사진.
- 색감: 짙은 브라운 우드·베이지·크림/화이트를 기본으로 하고 메뉴 고유 색을 유지한다.
- 조명: 따뜻하고 부드러운 자연광 또는 은은한 실내 광원. 강한 채도보다 차분한 명암.
- 배경: 우드 테이블·아이보리 벽·크림색 식기·패브릭·트레이 등에서 스타일에 맞는 요소를 사용한다. 모든 소품을 반드시 넣을 필요는 없다.
- 구도: 가까운 음식 사진 또는 테이블 위 정물, 상단·사선 구도, 중앙 또는 약간 비대칭 배치와 여백.
- 글자 배치: X. 이미지에 새 문구·날짜·로고를 삽입하지 않는다.
- 말투: 제품명으로 시작하고 2~4개의 짧은 문단으로 부드러운 존댓말을 사용한다.
- 이모지는 평가 대상에서 제외한다.
- 브랜드 포인트 색상: #76472e. 글자 삽입 없는 사진에 정확한 HEX 픽셀의 출현을 요구하지 않는다.
- Instagram 기존 게시물로부터 사용자가 제공한 스타일 설명을 모든 후보에 공통 입력으로 사용한다. 이번 시험에서 스타일 추출 정확도 자체는 평가하지 않는다.

## 이미지의 보존 대상

**화면 중앙에 가장 가까운 메인 쿠키 한 개만 보존한다. 출력의 대상 상품 수는 1개다.**
입력 사진에는 쿠키 9개가 보일 수 있지만 나머지 쿠키는 최종 이미지에서 제거한다. 9개 전부 보존이라는 종전 기준은 사용하지 않는다.

이번 사진의 대상은 큰 원형 스탠드 앞줄 오른쪽, 화면 중앙에 가까운 쿠키다. 가장 아래쪽의 쿠키나 작은 오른쪽 스탠드의 쿠키로 바꾸지 않는다. 각 변형 사진에서도 같은 메인 쿠키에 해당하는 개체를 사용한다.

보존할 특징:

- 갈색의 둥근 쿠키 형태와 표면 질감.
- 쿠키 위의 흰 유령 모양 장식.
- 짙은 눈·입의 배치와 유령 장식의 대략적인 비율.
- 쿠키와 장식이 붙어 있는 구조.

배경·조명·소품은 가게 스타일에 맞춰 바꾼다. 할로윈 주제 때문에 검정·보라 배경을 필수로 요구하지 않는다.
입력의 유효성은 최초 원본과 대조하고, 서비스 출력의 상품 보존은 그 실행에 실제 넣은 입력 속 메인 쿠키와 대조한다. 합성 입력에 이미 있던 차이를 서비스의 오류로 중복 계산하지 않는다.

## 출력 규격과 보관

- 최종 Instagram 피드 미리보기: **세로 4:5, 1080×1350 픽셀**.
- 모델이 반환한 생성 원본과 최종 미리보기를 둘 다 보관한다.
- 생성 원본의 크기·품질은 모델별 탐색 후 확정해 기록하되, 최종 비교 도중 임의 변경하지 않는다.
- 미리보기의 비율 변환 과정에서 메인 상품·유령 장식이 잘리면 서비스의 최종 이미지 품질 실패로 기록한다.
- 모델이 반환한 이미지의 문제와 이후 렌더링의 문제를 구분한다.

## 개별 문구 판정

필수 조건:

- T01: 본문에 스푸키쿠키와 쿠키 종류가 드러난다.
- T02: 본문에 할로윈과 연결되는 내용이 있다. 특정 문장 복사는 요구하지 않는다.
- T03: 10월 26일~11월 6일의 양쪽 날짜와 한정 판매 조건이 모두 정확하다.
- T04: 제목·본문·해시태그에 미제공 가격·재료·식감·제조 방식을 사실처럼 추가하지 않는다.
- T05: 본문이 제품명으로 시작한다. 평가 제외인 이모지와 공백은 첫 실제 내용 판정에서 무시한다.
- T06: 본문은 2~4개 짧은 문단이다. 끝의 해시태그 묶음은 본문 문단 수에서 제외한다.
- T07: 부드러운 존댓말을 사용한다.
- T08: `#할로윈 #카페 #대구카페 #쿠키`가 모두 포함된다.
- T09: 위 태그 외 추가는 최대 2개다. 중복을 제외한 전체 태그는 4~6개다.

날짜의 `10/26~11/6`과 `10월 26일~11월 6일`은 같은 의미로 인정한다. 월·일을 바꾼 표현은 인정하지 않는다.
본문의 필수 정보는 해시태그만으로 대신 충족하지 않는다. 해시태그 준수는 실제 노출·매출 효과의 증거가 아니다.

## 개별 이미지의 사람 판정

- H01 상품 보존: 선택한 메인 쿠키와 같은 상품으로 보이는가. 상품 수는 1개인가.
- H02 스타일 적합성: 따뜻한 색감·조명·정돈된 배경이 반영됐는가.
- H03 자연스러움: 상품과 배경의 경계·그림자·접촉면에 이상이 없는가.
- H04 최종 미리보기: 1080×1350이며 메인 상품·장식이 잘리지 않고 새 문구가 삽입되지 않았는가.

각 항목을 다음 중 하나로 판정하고 구체적인 이유 한 문장을 남긴다.

- 충족: 해당 기준에 뚜렷한 문제가 없다.
- 부분 충족: 일부는 맞지만 구체적인 문제가 남아 있다.
- 미충족: 기준과 명확히 어긋난다.
- 미평가: 아직 사람이 판정하지 않은 상태. 충족·실패로 대신 채우지 않는다.

**부분 충족은 개선 자료로 남기며 합격이 아니다.**
문구는 해당 필수 조건과 말투를 모두 충족해야 하고, 이미지는 해당 조건을 모두 충족해야 한다. 실제 완성본의 합격은 그 문구와 이미지가 모두 통과한 경우다.
AI가 작성한 사전 검수를 사람 판정으로 등록하지 않는다.

## 결과 묶음의 사람 검증

같은 모델·저장 스타일에서 나온 5개 결과를 같은 순서로 나란히 놓고 별도로 판정한다.

- 이미지: 색감·조명·배경 분위기가 같은 가게의 피드로 이어지는가.
- 문구: 말투·문장 길이·제품 설명 방식이 같은 가게의 캡션으로 이어지는가.

모델명·가격을 가리고 결과 순서를 섞어 검토한다.
판정은 충족/부분 충족/미충족으로 남기고, 상대 비교는 A 우세/비슷함/B 우세 및 이유를 별도로 기록한다.
묶음 판정 한 건을 사진 수만큼 독립 판정으로 중복 합산하지 않는다. 개별 합격과 묶음 일관성을 구분한다.
같은 픽셀이나 같은 문장을 복제해야 한다는 조건이 아니다.
기존 실제 피드와의 유사성까지 주장하려면 참고 게시물 이미지도 함께 검토해야 한다. 현재 자료만으로는 제공된 스타일 설명의 준수와 결과 간 일관성을 평가한다.

## 비용·시간

- 생성 시도당 비용: 원시 사용량과 해당 모델의 적용 단가로 계산한다.
- 품질 통과 완성본당 비용: 해당 모델·설정·실험 회차의 전체 비용 / 합격 완성본 수.
- 문구 단독·이미지 단독 비교에서는 각 영역의 비용과 합격 수를 분리한다. 실제로 조립·평가하지 않은 조합을 가상의 합격 완성본으로 늘려 세지 않는다.
- 청구된 실패·재시도 비용도 해당 실험에 포함한다.
- 비용 미확정과 예약 금액을 실제 확정 비용이나 0원으로 취급하지 않는다.
- 합격 수가 0이면 합격 완성본당 비용은 계산 불가다.
- 모델 처리 시간: 요청 전송부터 문구 또는 이미지 응답 완료까지.
- 사용자 대기 시간: 제작 버튼부터 이미지와 문구가 모두 준비된 미리보기까지.
- 병렬 작업 시간을 단순히 더해서 사용자 대기 시간이라고 표시하지 않는다.
- 실패·거절·결과 불명의 경과 시간과 사유도 남긴다.
- 합격한 후보끼리 비용·시간을 비교한다. 저렴한 후보와 빠른 후보가 다르면 두 장단점을 보고하고 우선순위 없이 단일 승자를 강제하지 않는다.

## 합성 입력의 증거 범위

원본 한 장을 AI로 변형한 네 사진은 **촬영 조건을 모사한 합성 입력**으로 사용한다.
이 자료에서 실제 생성·판정을 수행하면 “이 합성 입력 세트에서의 스타일·상품 보존 안정성”에 대한 증거가 된다.

이미지 파일을 다시 생성하거나 수정해도 실제 별도 촬영 자료로 바뀌지는 않는다. 실제 각도·조명만의 효과를 분리한 증거나 실제 촬영 전반의 재현성 입증으로 표기하지 않는다.
현재 각도·광원 조건은 프롬프트 목표이며 실측값이 아니고, 합성 과정에서 질감·윤곽도 일부 바뀌었다. 알려진 한계와 실패 결과를 함께 공개한다.
실제 촬영 환경에 대한 주장은 실제 별도 촬영 자료가 있어야 추가로 검증할 수 있다.

## 실행 전 고정할 설정과 상태

선택된 모델과 입력 수, 메인 상품 한 개, 불합격 규칙, 최종 미리보기 규격은 확정됐다.
각 모델의 정확한 생성 품질·원본 크기·출력 한도·추론 설정은 탐색 후 최종 비교 전에 확정한다. 이 문서는 아직 선택하지 않은 설정이나 API 호출 결과를 만들어 채우지 않는다.
생성 원본·사용량·시간·실패 상태와 사람 판정은 분리해 보관한다.
