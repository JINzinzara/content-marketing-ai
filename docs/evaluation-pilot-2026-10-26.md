# 평가 구현과 첫 파일럿 결과

2026-10-26. **대조군을 별도로 구현하고, 버전·입력·응답·시간·비용을 보존하는 실험을 실행했다.** 자동 행동 검사 23개는 모두 통과했고, 실제 GPT 생성 요청 8개 모두 구조화된 응답을 받았다. 사람의 작업 시간·최종 품질 평가는 아직 수행하지 않았다.

평가는 현재 서비스와 분리된 `evaluations/`의 CLI에서 실행한다. 2026-10-26 첫 파일럿은 자동 행동 검사 **23/23 통과**, 실제 GPT 응답 **8/8 수신**, 기록 비용 **$0.067687**이었다. 유료 API를 추가 호출하지 않고 GitHub의 최신 코드에 CLI를 적용해 회귀 검사를 수행한다. 공개 가능한 실행 수치는 [보고서용 CSV](../evaluations/reports/pilot-2026-10-26/README.md)에 보존하며, 원본 입력·응답·사진·설정은 로컬에 보관한다.

## 비교 방식

현재 앱 전체를 Baseline으로 삼지 않는다. 공지 대조군은 저장 서식의 날짜·메뉴·품절 문구를 직접 수정하는 방식이며, 서비스 방식은 저장 메뉴 선택과 상태 반영이다. 일반 홍보 피드는 양쪽 모두 같은 GPT API를 사용하고 직접 정보 입력과 저장 상품·스타일 재사용을 비교한다.

두 방식은 `baseline-v1`, `service-v1`로 구분한다. 방식 이름과 별도로 실제 소스 해시를 남겨 구현 변경을 구분한다. [정의·검수 기준·재실행 절차](evaluation-protocol.md)

## 자동 행동 검사

첫 파일럿 종료 시 자동 실행: `7ae529889dbc4a11aa465e8754afd891`. GitHub 통합본의 CLI 재검사는 `2b70be1b803f4144a0316dbce6f2c21e`이며 [공개 검사 결과](../evaluations/reports/pilot-2026-10-26/automated-checks.csv)에 보존한다. 이후 개인 실행의 전체 기록은 로컬 `evaluations/results/`에 추가한다.

소스 해시: `25915df294c3e4559cd067e20bc75bb292d5e3f8169c599e8487cda0215d6bd4`.

- G1 공지 구성·이미지 규격·품절 반영: **3/3 통과**.
- G2 빈칸 병합·기존 값 보존·근거 없는 빈칸 유지: **3/3 통과**.
- G3 MFT 기본 기능: **12/12 통과**.
- G3 INV 불변성: **3/3 통과**.
- G3 DIR 방향성: **2/2 통과**.

공지의 이번 서버 처리 시간은 라인업 스토리 9.10ms, 라인업 피드 3.75ms, 품절 스토리 4.17ms였다. 기존 사진 생성이나 사람 입력·검수·네트워크·브라우저 표시를 포함하지 않는다. 스토리 전체 5초 목표를 달성했다는 의미로 사용하지 않는다.

동일 실행의 홍보 피드 경로 3개는 별도 API·사람 평가 대기로 남아 있다. 실제 유료 문구 파일럿은 아래 다른 실행에서 기록했다. 개발 중 앞선 자동 실행들도 삭제하지 않고 집계 파일에 보존했다. 반복 실행을 서로 다른 평가 사례 수로 부풀리지 않는다.

## 실제 GPT 파일럿

요청 모델은 `gpt-5.4`, 응답 모델은 `gpt-5.4-2026-03-05`다. 배치 전체 소스 해시는 `710c2abdd6b61aa0d7cac10b0bd0c9fc0b62eb98d218e93c25c8ac75d96c7921`이다. 이후 결과 집계·사람 검수 기능을 보완했으며 앞선 호출의 소스 해시를 변경하지 않았다.

- 상품 소개 문구: baseline **4.312초**, service **2.568초**.
- 행사 안내 문구: baseline **3.442초**, service **2.782초**.
- 가게 소개 문구: baseline **2.230초**, service **1.860초**.
- 스타일 추출: **7.534초**.
- 인사이트 브리핑: **4.736초**.

위 시간은 생성 API 요청부터 응답 수신까지다. 입력 토큰 사전 조회는 CSV에 별도로 기록했다. 요청별 1회 측정이고 실행 순서는 고정했다. 출력 토큰 수도 다르므로 시간 차이로 서비스가 더 빠르다거나 모델을 가속했다고 결론 내릴 수 없다.

홍보 문구 **6/6건이 제한된 숫자·미확인 표현 검사**를 통과했다. 이 검사는 일부 표현만 검사하므로 할루시네이션 0건·최종 사실 정확도 100%로 보고하지 않는다. 스타일 추출과 브리핑도 원본 응답은 보존했지만 사람의 품질 판정은 대기 상태다.

입력 사진은 동일한 640×480 합성 단색 이미지다. 문구·모델 연결·계측을 확인하는 좁은 범위의 파일럿이며 실제 상품 사진이나 이미지 편집을 평가하지 않았다. 스타일 추출에 정답 프로필을 입력하지 않았다. 새 상품 제작에 전달한 저장 스타일은 정보 재사용 실험용 설정이다.

생성 요청 8건과 각각의 입력 토큰 사전 조회를 수행했다. 이번 생성 비용의 앱 기록액은 **$0.067687**, 미확정 비용은 0건이다. 기존 운영 원장 확인액은 총 **$0.156753 / 설정 한도 $5.00**이다. 기록액은 앱의 설정 단가로 계산한 값이며 청구서와 구분한다. 기존 예산과 비용 원장을 재사용했고 한도를 늘리거나 원장을 초기화하지 않았다.

## 코드 검증

- 첫 파일럿 당시 전체 테스트: **139개 통과, 3개 실패**. 실패한 3개는 작업 전부터 있었던 `Instagram.sync_history()`와 호출부의 `restore_deleted` 인자 불일치다. 기존 Instagram 변경을 덮어쓰지 않았다.
- GitHub 최신 코드를 유지한 통합본 검사: **전체 138개 통과, 실패 0개**. 평가 전용 CLI 검사 24개가 포함되어 있다. 앞서 로컬에서 발생한 3개 실패는 이번 통합본에서 재현되지 않았다. [검증 수치](../evaluations/reports/pilot-2026-10-26/verification.json)를 보존했다.
- 의존성 검사: 충돌 없음. 기존 Starlette/httpx 사용 중단 예정 경고 1개는 남아 있다.
- 현재 앱에는 평가 경로와 메뉴가 없다. 터미널 자동 실행·결과 파일·원본 응답 보존·평가 코드의 비용 한도 재사용을 검사한다. 공지 이미지의 날짜·메뉴·품절 표시는 자체 확인했으며 사람의 사용성 평가로 간주하지 않는다.

이번 실험 코드는 이 작업 폴더의 저장소에 구현했다. 제공받은 Desktop 프로젝트의 `.env`와 비용 원장은 실제 API 배치에 사용했고, 해당 폴더의 앱 소스는 수정하지 않았다.

## 보고서용 증거와 남은 평가

저장소에는 [호출별 수치와 자동 검사 결과](../evaluations/reports/pilot-2026-10-26/README.md)를 보존한다. 미평가 값은 0 대신 빈칸으로 남긴다. 전체 실행 집계·원본 JSON·시도별 CSV·사람 판정·소스 ZIP은 로컬의 `evaluations/results/`에 보관하며, CLI를 실행하면 같은 구조로 새 결과를 만들 수 있다.

현재 비교 가능한 사람 과제 쌍은 **0개**다. 실제 사람이 과제를 수행한 시간과 수정 회차를 별도로 관찰해 기록해야 한다. 기존 API 응답의 항목별 품질은 입력과 결과를 대조해 JSON으로 작성하고 CLI로 집계할 수 있다. 동료 모집이 어렵다면 개발자 자체 평가로 명시하고 독립 평가로 해석하지 않는다.

다음에 필요한 검증은 실제 상품 사진을 사용한 생성 품질, 최초 스타일 설정 시간, 사람이 수행한 전체 제작 시간과 수정 회차, 여러 영업일의 상태 유지다. 실제 Instagram 인사이트 수집·게시·자동 스타일 가져오기 전체 흐름·GPT 이미지 편집·실제 고객 재사용·홍보 및 매출 효과는 이번 결과의 검증 범위 밖이다.
